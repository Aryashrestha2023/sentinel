Detection Model
Online z-score detection
Explainable, deterministic, and constant-memory. Welford's algorithm updates the running mean and variance with each event — no historical data retained.

Welford's Algorithm

z = |x − μ| / σ

After a configurable warmup phase (default: 30 events per entity/metric key), each incoming value is scored against the running baseline. The algorithm updates mean and variance in O(1) using Bessel-corrected incremental computation — no event history is stored.
