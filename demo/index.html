◆ src/main/java/com/taniyanandi/sentinel/domain/DetectionState.java 
package com.taniyanandi.sentinel.domain;

import java.io.Serializable;

public class DetectionState implements Serializable {
    private long count;
    private double mean;
    private double m2;

    public DetectionState() {}

    public void observe(double value) {
        count++;
        double delta = value - mean;
        mean += delta / count;
        double delta2 = value - mean;
        m2 += delta * delta2;
    }

    public long count() { return count; }
    public double mean() { return mean; }
    public double variance() { return count > 1 ? m2 / (count - 1) : 0.0; }
    public double stdDev() { return Math.sqrt(variance()); }
}
Welford's online algorithm. Updates mean and variance in O(1) memory per key using Bessel-corrected incremental computation. The m2 field accumulates the sum of squared differences — no event history is ever stored. This class is serialized into Kafka Streams' persistent RocksDB state store, keyed by entityId|metric.
◆ src/main/java/com/taniyanandi/sentinel/service/AnomalyDetector.java 
@Service
public class AnomalyDetector {
    private final long warmupEvents;
    private final double zThreshold;
    private final SentinelMetrics metrics;

    public AnomalyDetector(
            @Value("${sentinel.detector.warmup-events:30}") long warmupEvents,
            @Value("${sentinel.detector.z-threshold:3.0}") double zThreshold,
            SentinelMetrics metrics) {
        this.warmupEvents = warmupEvents;
        this.zThreshold = zThreshold;
        this.metrics = metrics;
    }

    public AnomalyAlert evaluate(TelemetryEvent event, DetectionState state) {
        return metrics.detectionLatency().record(
            () -> evaluateInternal(event, state));
    }

    private AnomalyAlert evaluateInternal(TelemetryEvent event, DetectionState state) {
        // Skip detection during warmup or if stdDev is negligible
        if (state.count() < warmupEvents || state.stdDev() < 1e-9) {
            state.observe(event.value());
            return null;
        }

        double mean = state.mean(), stdDev = state.stdDev();
        double z = Math.abs(event.value() - mean) / stdDev;
        state.observe(event.value());

        if (z < zThreshold) return null;

        AnomalyAlert.Severity severity =
            z >= 6 ? AnomalyAlert.Severity.CRITICAL :
            z >= 5 ? AnomalyAlert.Severity.HIGH :
            z >= 4 ? AnomalyAlert.Severity.MEDIUM :
                     AnomalyAlert.Severity.LOW;

        metrics.anomalyDetected(severity == AnomalyAlert.Severity.CRITICAL);

        return new AnomalyAlert(
            UUID.randomUUID().toString(),
            event.eventId(), event.entityId(), event.metric(),
            event.value(), mean, stdDev, z, severity,
            "Value deviated " + String.format("%.2f", z)
                + " standard deviations from baseline",
            Instant.now());
    }
}
The core detection loop. Z-score is computed before the new value updates the baseline — so the current observation doesn't shift the statistics it's measured against. Detection latency is instrumented via Micrometer's Timer. Config: warmup = 30, z-threshold = 3.0 from application.yml.
◆ src/main/java/com/taniyanandi/sentinel/stream/EventStreamProcessor.java 
@Configuration
public class EventStreamProcessor {
    private final AnomalyDetector detector;
    private final String eventsTopic;   // sentinel.events
    private final String alertsTopic;   // sentinel.alerts

    @Bean
    KStream<String, TelemetryEvent> topology(StreamsBuilder builder) {
        // Persistent state store backed by RocksDB
        StoreBuilder<KeyValueStore<String, DetectionState>> stateStore =
            Stores.keyValueStoreBuilder(
                Stores.persistentKeyValueStore("baseline-store"),
                Serdes.String(), stateSerde);
        builder.addStateStore(stateStore);

        KStream<String, TelemetryEvent> events =
            builder.stream(eventsTopic, Consumed.with(Serdes.String(), eventSerde));

        KStream<String, AnomalyAlert> alerts = events
            // Re-key by entityId|metric for per-key state isolation
            .selectKey((key, event) ->
                event.entityId() + "|" + event.metric())
            .transform(() -> new Transformer<>() {
                private KeyValueStore<String, DetectionState> store;

                @Override
                public void init(ProcessorContext context) {
                    store = context.getStateStore("baseline-store");
                }

                @Override
                public KeyValue<String, AnomalyAlert> transform(
                        String key, TelemetryEvent event) {
                    DetectionState state = store.get(key);
                    if (state == null) state = new DetectionState();
                    AnomalyAlert alert = detector.evaluate(event, state);
                    store.put(key, state);
                    return alert == null ? null
                        : KeyValue.pair(key, alert);
                }
            }, Named.as("anomaly-detector"), "baseline-store")
            .filter((key, alert) -> alert != null);

        alerts.to(alertsTopic, Produced.with(Serdes.String(), alertSerde));
        return events;
    }
}
Kafka Streams topology. Events are re-keyed by entityId|metric so each key gets its own DetectionState in the persistent state store. The transformer loads state from RocksDB, runs detection, writes state back, and emits alerts downstream. Runs with processing.guarantee: exactly_once_v2.
◆ src/main/java/com/taniyanandi/sentinel/service/AlertPersistenceListener.java 
@Component
public class AlertPersistenceListener {
    private final AlertRepository repository;

    public AlertPersistenceListener(AlertRepository repository) {
        this.repository = repository;
    }

    @Transactional
    @KafkaListener(
        topics = "${sentinel.kafka.alerts-topic:sentinel.alerts}",
        groupId = "sentinel-alert-persistence")
    public void persist(AnomalyAlert alert) {
        // Idempotent: skip if alert already persisted
        if (repository.existsById(alert.alertId())) return;

        repository.save(new AlertEntity(
            alert.alertId(), alert.eventId(),
            alert.entityId(), alert.metric(),
            alert.value(), alert.baselineMean(),
            alert.baselineStdDev(), alert.zScore(),
            AlertEntity.Severity.valueOf(alert.severity().name()),
            alert.reason(), alert.detectedAt()));
    }
}
Idempotent persistence. The listener consumes from the sentinel.alerts topic and writes to PostgreSQL. The existsById check ensures duplicate delivery (from Kafka rebalances or retries) never creates duplicate rows. This sink is not part of the Kafka transaction — a deliberate design choice documented in ADR-002.

◆ src/main/java/com/taniyanandi/sentinel/metrics/SentinelMetrics.java 
@Component
public class SentinelMetrics {
    private final Counter ingested;
    private final Counter anomalies;
    private final Counter criticalAnomalies;
    private final Timer detectionLatency;

    public SentinelMetrics(MeterRegistry registry) {
        ingested = Counter.builder("sentinel.events.ingested")
            .description("Events accepted by the ingestion API")
            .register(registry);

        anomalies = Counter.builder("sentinel.anomalies.detected")
            .description("Anomalies emitted by the detector")
            .register(registry);

        criticalAnomalies = Counter.builder("sentinel.anomalies.critical")
            .description("Critical anomalies emitted")
            .register(registry);

        detectionLatency = Timer.builder("sentinel.detection.latency")
            .description("Anomaly detection evaluation latency")
            .register(registry);
    }

    public void eventIngested() { ingested.increment(); }
    public void anomalyDetected(boolean critical) {
        anomalies.increment();
        if (critical) criticalAnomalies.increment();
    }
    public Timer detectionLatency() { return detectionLatency; }
}
Micrometer instrumentation. Four metrics scraped by Prometheus: ingestion volume, anomaly rate, critical anomaly rate, and detection latency. These feed the Grafana dashboards for production observability.

Detection Model
Online z-score detection
From AnomalyDetector.evaluateInternal() — explainable, deterministic, constant-memory.

Welford's Algorithm

z = |x − μ| / σ

After warmupEvents (30) observations per entityId|metric key, each incoming value is scored against the running baseline. The z-score is computed before state.observe() updates the mean — so the observation doesn't shift the statistics it's measured against.
